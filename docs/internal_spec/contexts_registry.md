# Реєстр обмежених контекстів системи SafeVault
Система поділяється на 3 основні функціональні модулі:
1. **Account** — керування тимчасовими сесіями авторів, генерація токенів доступу (`access_token`) та відкликання (`revoke_token`).
2. **Vault** — шифрування конфіденційних нотаток алгоритмом AES-256-GCM, контроль лічильника переглядів (`max_views`) та часу життя (`ttl_minutes`).
3. **Audit** — фіксація подій безпеки (`CREATED`, `ACCESSED`, `CONSUMED`, `EXPIRED`, `REVOKED`) без запису відкритого тексту секретів.
