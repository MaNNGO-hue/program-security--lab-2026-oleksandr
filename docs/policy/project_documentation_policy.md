# Політика супроводу документації (ISO/IEC/IEEE 29148:2018 та SDD)
* Документація у каталозі `docs/` є первинним джерелом істини (підхід Specification-Driven Development).
* Усі вимоги повинні бути структурованими, атомарними, однозначними та вимірюваними (відповідно до ISO/IEC/IEEE 29148:2018).
* Будь-яка зміна вимог спочатку фіксується в документації комітом із префіксом `[DOCS]`, а потім реалізується в коді.
